# Versión 1.1 — Gestor de Tarjetas Pro

**Fecha de lanzamiento:** Mayo 2026
**Tipo:** Actualización visual / Refactoring de colorimetría

## 1. Resumen Ejecutivo

La versión **1.1** representa la primera actualización visual significativa del proyecto. Se realizó una modernización completa de la identidad de color de la aplicación, reemplazando el esquema azul/slate original por una paleta derivada de verdes profundos forestales, extraída directamente de una imagen de referencia de Adobe Color.

**Ninguna funcionalidad fue modificada.** Firebase, Pinia, Vue Router, lógica financiera, PWA, Service Worker, manifest, GitHub Pages y toda la lógica de negocio permanecen 100% intactos.

## 3. Filosofía de Diseño v1.1

### Paleta financiera profesional
La paleta de verdes profundos transmite:
- **Confianza y estabilidad** — fundamental en apps financieras
- **Naturaleza y crecimiento** — metáfora visual del crecimiento del patrimonio
- **Sobriedad y profesionalismo** — sin colores agresivos ni neon

### Semántica de colores conservada
Se respetó la semántica financiera estándar:
- **Rojo** (`#c0392b`): Deuda total, montos negativos, alertas críticas
- **Verde** (`#5c8b32`): Disponible, pagado, éxito
- **Ámbar** (`#d4801a`): Uso moderado del crédito (50-70%)

### Contraste y accesibilidad
- Texto principal `#0f0e0b` sobre fondos `#ffffff` o `#f4f7f0`: ratio > 7:1 ✅
- Texto secundario `#6b7c5e` sobre `#ffffff`: ratio > 4.5:1 ✅
- Botones `#ffffff` sobre `#5c8b32`: ratio > 4.5:1 ✅

## 5. Actualizaciones en Charts

### Doughnut (Uso de Crédito)
```
ANTES: deuda #ef4444 (rojo saturado), disponible #10b981 (esmeralda)
AHORA: deuda #c0392b (rojo cálido elegante), disponible #5c8b32 (verde oliva)
```
Se añadió una leyenda visual debajo del donut para mayor claridad.

### Line Chart (Evolución de Deuda)
```
ANTES: borderColor #3b82f6 (azul), fill rgba(59,130,246,0.1)
AHORA: borderColor #5c8b32 (verde), fill rgba(92,139,50,0.12)
       pointBackgroundColor #8fbf45 (lima), ejes color #6b7c5e
```
Se ajustaron los colores de la cuadrícula para un resultado más limpio y alineado con la paleta.

### Gráfica de Proyecciones (ProjectionsView)
Mismos cambios que el line chart del Dashboard.

## 6. Mejoras Visuales Aplicadas

- **Gradiente de fondo en login/registro:** Sutil gradiente `#f4f7f0 → #eef3e8 → #e0edd6` para mayor profundidad visual
- **Hover effects en botones:** Transición `#5c8b32 → #184000` con inline JS para compatibilidad con Tailwind v4
- **Scrollbar temática:** Track verde claro, thumb verde medio, hover verde primary
- **Sidebar gradient:** `#082901 → #184000` (arriba a abajo), sensación de profundidad forestal
- **Avatar gradient:** `#5c8b32 → #8fbf45` (antes azul → morado)
- **Focus states en inputs:** Border verde al enfocar, suave y profesional
- **Legend en Doughnut:** Añadida para mejor comprensión financiera
- **Ejes de gráficas con color temático:** `#6b7c5e` en lugar del gris predeterminado
- **Grid lines suavizadas:** `rgba(212,224,200,0.5)` para las líneas de cuadrícula
